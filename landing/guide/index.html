01

설치 전에 준비하기

저장소가 명시한 요구 사항은 macOS 14 이상, Homebrew, Xcode Command Line Tools입니다. Apple Silicon과 Intel Mac을 대상으로 하며, 외부 패키지의 버전은 고정되어 있지 않습니다.

  • Homebrew가 없다면 공식 설치 안내 ↗를 먼저 따르세요.
  • 터미널에서 아래 명령으로 Command Line Tools를 준비합니다. 설치 안내가 나오면 설치를 마친 뒤 다음 단계로 넘어갑니다.
  • 기존 SketchyBar·AeroSpace 설정과 다른 창 관리 도구의 사용 여부를 확인하세요.
확인할 결과
Homebrew 버전과 Command Line Tools 경로가 표시되면 설치 준비가 끝납니다.

04

바를 읽고 작업 공간 이동하기

바 왼쪽의 번호를 클릭하거나 ⌥ 1–9를 눌러 워크스페이스를 선택합니다. 번호 옆에는 현재 앱 이름이 표시됩니다.

먼저 익힐 세 가지

  • ⌥ 2로 2번 공간에 이동합니다.
  • ⌥⇧ 1로 현재 창을 1번 공간에 보냅니다.
  • ⌥ Tab으로 직전 공간에 돌아갑니다.
확인할 결과
이동한 번호의 바탕이 파란색으로 바뀝니다. 비어 있는 번호가 바에 없어도 단축키로 이동할 수 있습니다. 이 번호는 AeroSpace의 작업 공간이며 macOS 기본 Spaces와는 구분됩니다.

06

AI 사용량과 팝업 읽기

상단의 Claude, Codex, Cursor를 클릭하면 해당 팝업이 전환되면서 조회를 시작합니다. 다른 공급자의 팝업은 닫히며, 마우스가 벗어나면 팝업이 닫힙니다.

  • 26m / 5h9m / 4d19h: 초기화까지 26분 / 5시간 9분 / 4일 19시간.
  • 3P: Cursor의 서드파티 한도. ↺N: 남아 있는 재설정 크레딧 횟수.
  • 기본 갱신은 300초입니다. 클릭은 조회를 시작하며 완료 시간은 외부 도구·서비스에 달려 있습니다.
  • 플랜 행 1개 아래에 세부 행 최대 6개가 표시됩니다. 추가 한도 이름과 플랜은 계정·조회 결과에 따라 달라집니다.
  • 바의 색은 기본 한도 3개 중 최대 사용률을 기준으로 50% 미만 녹색, 50–79% 황색, 80% 이상 적색입니다. 추가 한도 전체를 합산한 경고는 아닙니다.
확인할 결과
바에서 사용률과 초기화 시간을 읽고, 클릭한 팝업에서 해당 한도 제목을 확인합니다. …은 초기 상태, 회색 ?는 조회 결과 처리 실패입니다.
07

macOS 메뉴바 사용하기

마우스를 화면 맨 위에 약 0.6초 두면 SketchyBar가 숨겨지고 macOS 메뉴바를 사용할 수 있습니다.

  • 열린 메뉴를 닫고 커서를 아래로 내리면 상단 바가 돌아옵니다.
  • 바가 돌아오지 않으면 Esc로 열린 메뉴를 먼저 닫으세요.
  • SketchyBar의 팝업이 열려 있으면 메뉴바 전환을 억제합니다.
  • README의 ⌃ F2는 macOS 메뉴바 접근 키이며 키보드 설정에 따라 달라질 수 있습니다.
확인할 결과
메뉴를 닫고 화면 좌표 기준 상단에서 44보다 아래로 내렸을 때 SketchyBar가 다시 보입니다.

~/.config/sketchybar/sketchybarrc에서 아래 값을 수정합니다.

시계의 auto 기준은 연결된 화면 중 가장 좁은 폭 1800pt입니다. 물리 픽셀 해상도 기준이 아닙니다. 겹치면 CLOCK_POSITION=right로 고정하거나 공급자 수를 줄이세요.

서비스 모드의 R은 레이아웃 초기화, F는 플로팅·타일 전환입니다. Backspace는 현재 창을 제외한 창을 닫습니다. 단순 확인용으로 누르지 마세요.

기본 배치 재현 · 3대 이상은 첫 3대에 분배하며, 4번째 이후 번호 자동 할당은 없습니다.

기본 관리기는 바 시작·디스플레이 변경·잠자기 해제 시 [workspace-to-monitor-force-assignment] 블록을 다시 씁니다. 수동 배치를 유지하려면 sketchybarrc에서 monitor_ctl 항목의 생성·구독 설정과, 바로 아래 monitor_layout.sh를 실행하는 줄을 함께 제거하세요. 시작 시 실행하는 줄이 남아 있으면 바를 다시 읽을 때 수동 배치가 덮어써집니다. 10초 주기는 바 표시 갱신이며 배치 재작성 주기와 다릅니다.

설치 옵션의 정확한 범위

--link

복사 대신 저장소 설정을 연결합니다. 헬퍼 빌드와 모니터 배치 재작성도 연결 대상 파일에 영향을 줄 수 있습니다.

--no-aerospace

AeroSpace 설치·설정 교체·실행을 생략합니다. 바의 워크스페이스·모니터 플러그인은 남으므로 기존 AeroSpace가 실행 중이면 기존 설정을 읽거나 수정할 수 있습니다.

--no-ai

CodexBar 설치·앱 실행을 생략합니다. 이미 codexbar CLI가 있으면 기본 AI 항목이 나타날 수 있습니다. 표시를 숨기려면 AI_PROVIDERS=""로 설정하세요.

--no-brew

패키지 설치만 생략합니다. Swift 빌드·설정 변경·서비스 실행은 남으므로 필요한 실행 파일이 모두 준비되어 있어야 합니다.

메뉴바 감도 변경

Swift 헬퍼의 revealEdge, restoreBelow, dwell을 수정하고 다시 빌드해야 합니다. 기본값은 화면 좌표 기준 상단 2, 복귀 경계 44, 머무는 시간 0.6초입니다. Retina 화면의 물리 픽셀 수를 뜻하지 않습니다.

09

데이터 처리와 제거 범위

별도 개인정보처리방침은 저장소에 없습니다. 아래는 프로젝트 스크립트에서 확인한 범위이며 외부 도구 전체의 처리를 보증하지 않습니다.

Mac 상태

AeroSpace 작업 공간, 현재 앱, CPU·배터리·볼륨·네트워크 상태를 읽어 로컬 바에 표시합니다. 메뉴바 헬퍼는 커서 위치와 창의 경계·소유자·레벨을 조회합니다. 화면 이미지를 캡처하는 코드는 없습니다.

AI 조회

CodexBar CLI의 JSON을 임시 디렉터리에 저장해 읽고, 정상 스크립트 완료 시 삭제합니다. 중단 시 정리 트랩은 없으며 암호화나 완전 삭제를 보장하지 않습니다.

외부 연결

설치는 Homebrew·GitHub를 사용합니다. 계정 연결과 조회는 CodexBar 및 공급자 서비스에 의존하며, 공급자에 따라 CLI 로그인·브라우저 쿠키 등 인증 수단을 사용할 수 있습니다.

설정과 백업

설정 파일을 복사 또는 연결하고 기존 파일을 날짜별로 백업합니다. 자체 분석 서버·추적 SDK·토큰과 쿠키를 직접 읽는 구현은 프로젝트 스크립트에서 확인되지 않았습니다.

설정을 제거하려면

  • SketchyBar와 AeroSpace의 두 설정 위치에서 가장 최근 백업을 복원합니다.
  • 백업이 없는 경로는 현재 설정이 삭제될 수 있습니다. 설치 옵션과 무관하게 세 경로를 처리합니다.
  • Homebrew 패키지는 유지됩니다. JankyBorders·CodexBar의 완전 종료도 보장하지 않습니다.
  • 이전 바 설정이 없으면 메뉴바를 항상 표시하도록 바꿉니다. 설치 전 자동 숨김 상태를 별도로 저장하지 않습니다.
  • 설치 전 환경 전체를 완전히 복원하는 기능은 아닙니다.
확인할 결과
복원 안내와 실제 설정 파일을 확인하세요. 이전 바 설정이 있으면 다시 읽고, 없으면 SketchyBar를 중지합니다.
10

문제 해결·FAQ

표시가 멈추거나 창이 정렬되지 않으면 아래 순서로 원인을 확인하세요. 명령은 직접 진단할 때 사용하며 이 사이트에서 실행하지 않습니다.

AI 사용량이 ?로 표시돼요.

CodexBar에서 공급자를 켜고 연결 상태를 확인합니다. 터미널에서 아래 조회를 실행해 로그인 안내나 오류가 있는지 확인하세요.

codexbar usage --provider claude

CLI 조회는 정상인데 바만 ?이면 갱신 이벤트를 실행합니다.

sketchybar --trigger ai_usage_refresh
워크스페이스 표시와 단축키가 멈췄어요.

AeroSpace가 실행 중인지 확인합니다. 첫 명령에 프로세스가 나오지 않으면 두 번째 명령으로 실행하세요.

pgrep -l AeroSpace
open -a AeroSpace

실행 중이라면 시스템 설정의 손쉬운 사용에서 AeroSpace를 껐다 켠 뒤 앱을 다시 실행하세요.

시계와 오른쪽 항목이 겹쳐요.

CLOCK_POSITION=right로 고정하거나 AI_PROVIDERS의 공급자 수를 줄인 뒤 아래 명령을 실행하세요. 모니터 연결·해제 뒤에도 위치를 다시 정합니다.

sketchybar --reload
아이콘이 네모로 보여요.

Nerd Font 설치 여부를 확인하고 다시 읽습니다.

brew install --cask font-caskaydia-mono-nerd-font
sketchybar --reload
macOS 메뉴바를 누를 수 없어요.

sketchybarrc의 topmost가 window인지 확인하세요. on은 메뉴바를 가릴 수 있습니다. sketchybar --query bar는 window 모드도 “on”으로 표시하므로 설정 파일을 확인하세요. 열린 메뉴는 Esc로 닫습니다.

모니터를 바꾸면 수동 배치가 사라져요.

기본 monitor_ctl 관리기가 배치 블록을 다시 쓰기 때문입니다. 수동 배치를 유지하려면 설정·모니터 안내에 따라 항목의 생성·구독 설정과 시작 시 배치 스크립트를 실행하는 줄을 함께 제거하세요. 기본 6–9의 보조 모니터 지정에는 메인 폴백이 포함되어 있습니다.

바에 항목 이름만 있고 값은 비어 있어요.

플러그인이 sketchybar 명령을 찾지 못할 수 있습니다. which sketchybar로 설치 위치를 확인하고 AeroSpace의 [exec.env-vars] PATH에 포함되는지 확인하세요. AeroSpace는 Launchpad·Spotlight에서 실행하는 편이 셸 환경 변수의 전달을 줄일 수 있습니다.

Ghostty 창을 닫아도 Dock에 인스턴스가 남아요.

⌘ Enter는 매번 새 인스턴스를 엽니다. ~/.config/ghostty/config에 아래 값을 추가하면 마지막 창을 닫을 때 종료하도록 설정할 수 있습니다.

quit-after-last-window-closed = true

이미 남은 인스턴스는 Dock에서 상태를 확인한 뒤 종료하세요.

AI 없이 쓰거나 여러 Mac에 설정을 옮길 수 있나요?

AI 없이 일반 바와 창 관리를 쓸 수 있습니다. AI를 숨기려면 AI_PROVIDERS=""로 설정하세요. Git과 --link는 설정 관리 방식이며 기기 간 자동 동기화 기능은 없습니다.

환경에 따라 결과가 다를 수 있습니다. 해결되지 않으면 재현 상황을 이슈로 남겨 주세요.
